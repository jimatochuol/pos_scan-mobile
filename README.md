
# POS Scan Mobile

An Android Point of Sale and Inventory Management Application.

## Features
- Barcode scanning
- Manual product registration
- Product inventory management
- Sales and checkout
- USD and SSP currencies
- Sales history
- Offline functionality
- Digital receipts

## Technology
- HTML
- CSS
- JavaScript
- Capacitor
- SQLite
- GitHub Actions

## Project Status
Development in progress.

## Platform
Android
